URDF 能讲什么？

link / joint、局部 origin、axis、限位与惯量。机械树不是线束走向。

MJCF 能讲什么？

刚体、碰撞、执行器与传感器的仿真模型。actuator 编号不是实机电机 ID。

真机还缺什么？

电气资料、设备映射、标定、反馈与安全验收。模型编译通过不等于可以下发运动。

这是 GitHub Pages 网页版。学习进度保存在当前浏览器。左侧选择实验，拖动三维画面改变观察角度，滑块只改变实验参数；观察视角不会改变数值结果。

  • 右手坐标系、列向量、主动旋转：p′ = R p。默认世界 Z 向上；相机自身坐标另有明确标注。
  • T_WB 把 B 系坐标变成 W 系坐标：p_W = R_WB p_B + t_WB。下标顺序是“目标坐标系在前，来源在后”。
  • 欧拉角：本工具使用固定轴外禀 xyz：先绕世界 X，再 Y，再 Z；矩阵 R = Rz(yaw) Ry(pitch) Rx(roll)。对应 SciPy 小写 'xyz'，不是大写 'XYZ'。
  • 四元数：基础数学默认 [x, y, z, w]，即标量在后；项目 Graphdeco 源码是 wxyz，已单独标注。可切换显示，但不要把两种顺序混用。q 与 −q 表示同一个旋转。
  • 单位：位置为米，姿态角显示为度，URDF 关节角标 rad、移动关节标 m，内部角度为弧度。导入真实机器人代码前核对 mm/m、角度单位、坐标方向与四元数布局。
  • 示例边界：门和夹爪只演示刚体几何，不能证明抓取成功、接触保持或运动无碰撞。基础 Python 示例不是控制程序。“项目”模块提取了真实参数、源码和记录，但不执行实机控制或物理仿真；新增 URDF / IK 页做数值运动学教学；MuJoCo 页使用官方 WASM 引擎单独运行教学物理模型。MJCF 四元数为 wxyz；本地原包烤箱保持资产原坐标，不套用 Scene2 的放置/尺度。

数学状态可在开发者控制台调用 GeometryLab.selfTest() 检查。快捷键：不在输入控件内时，← / → 切换实验；空格播放或暂停。
